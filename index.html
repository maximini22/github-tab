Grid sets the step size for the whole project, like snap in a DAW: every column is one grid step and Next moves one step. Changing it never moves or deletes notes; a note that sits between grid lines shows an amber dot. Tap the timeline to move the green playhead (drag to scrub); tap a string to pick a fret, the teal box is where you are editing.

Play resumes from the playhead (from the loop start if the playhead is outside the loop). From start goes to the loop start, or the top of the track when the loop is off. Stop leaves the playhead where it stopped; press Stop again to return to the start.
